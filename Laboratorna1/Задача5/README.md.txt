# Задание 5: Оценка студента

## Описание работы
Программа принимает оценку студента в числовом виде (0-100) и выводит ее текстовый эквивалент по шкале: отлично (90+), хорошо (75-89), удовлетворительно (60-74), неудовлетворительно (ниже 60).

## Синтаксис операторов
- **Разветвление:** `if-else if`

## Алгоритм
1. Ввод оценки (grade).
2. Проверка границ: если оценка < 0 или > 100, вывести ошибку.
3. Проверка условий по убыванию:
    - Если `grade >= 90` -> "отлично"
    - Иначе, если `grade >= 75` -> "хорошо"
    - Иначе, если `grade >= 60` -> "удовлетворительно"
    - Иначе -> "неудовлетворительно"
