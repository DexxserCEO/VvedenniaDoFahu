# Задание 3: Операторы Инкрементации и Декрементации

## Описание работы
Программа демонстрирует работу префиксной (`++X`) и постфиксной (`X++`) инкрементации, а также оператора декрементации (`Y--`).

## Синтаксис операторов
- **Постфиксный инкремент:** `X++` (сначала используется значение, потом увеличивается).
- **Префиксный инкремент:** `++X` (сначала увеличивается значение, потом используется).
- **Декремент:** `Y--` (уменьшение значения на 1).

## Алгоритм
1. Инициализация переменных X и Y.
2. Демонстрация постфиксного инкремента: `Z = X++`. Пояснение, что Z получает старое значение X.
3. Демонстрация префиксного инкремента: `Z = ++Y`. Пояснение, что Z получает уже увеличенное значение Y.
4. Демонстрация декремента: `Y--`.
